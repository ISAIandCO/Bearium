# Конфиденциальность Bearium

Bearium — независимый браузер для Android с открытым исходным кодом.
Проект поддерживается ISAIandCO: https://github.com/ISAIandCO/Bearium.
Обращения по конфиденциальности: https://github.com/ISAIandCO/Bearium/issues.
Не публикуйте там пароли, историю посещений или другие личные данные.

История, закладки, настройки и исключения проверки сертификатов используются
для работы браузера. Их можно удалить через настройки приложения; удаление
данных приложения средствами Android очищает его локальное хранилище.
Скачанные пользователем файлы могут оставаться в общей папке загрузок.

Посещаемые сайты и выбранные поисковые системы получают сетевые запросы,
включая IP-адрес и данные, которые пользователь им передаёт. Предложения поиска,
проверки безопасности, обновления расширений и другие сетевые функции могут
обращаться к соответствующим сторонним сервисам. Их обработка данных регулируется
также условиями этих сервисов. Дополнения могут запрашивать собственные разрешения.

В сборочной конфигурации Bearium отключены Fenix telemetry и crash reporting.
Это не отключает весь сетевой обмен браузера. Дополнительные функции Mozilla,
включая синхронизацию при входе в Mozilla Account, используют инфраструктуру
Mozilla и её правила обработки данных. Bearium не является продуктом Mozilla.

Проверка Russian Trusted Root CA и SCT выполняется в браузере с использованием
встроенных данных. Исключения изменяют правила локальной проверки; пользователь
может просмотреть и удалить их в интерфейсе защиты.

При WebAuthn биометрическое подтверждение обрабатывает Android и выбранный
провайдер ключей доступа. Bearium не получает изображение лица или отпечатка.
Сайт получает результат протокола аутентификации; хранение и синхронизация passkeys
зависят от выбранного провайдера.

Камера, микрофон и геолокация используются для разрешённых пользователем функций
сайтов. Разрешения можно отозвать в настройках сайтов и Android.

Владелец публикации должен поддерживать этот документ в соответствии с фактическим
составом выпуска. Для первого выпуска необходимо сверить сетевые функции и
SDK с декларацией Data safety и добавить контактный email издателя из Play Console.
