# Использование Bearium

Bearium — независимая модификация Firefox для Android. Проект не выпускается,
не поддерживается и не одобряется Mozilla. Официальные сервисы Mozilla,
если пользователь ими пользуется, имеют собственные условия.

Исходники Bearium распространяются по MPL-2.0; компоненты upstream сохраняют
свои лицензии и уведомления. См. LICENSE, NOTICE.md и исходники точной ревизии
Mozilla, указанной в сведениях о сборке.

Программное обеспечение предоставляется на условиях применимых лицензий,
включая положения об отсутствии гарантий. Контроль сертификатов не гарантирует
защиту от всех атак. Пользователь сам управляет исключениями; исключение снижает
соответствующие ограничения проверки.

Просмотр сайтов не требует собственного аккаунта Bearium. Условия сайтов,
поисковых систем, провайдеров passkeys и дополнений действуют отдельно.
Вопросы по проекту: https://github.com/ISAIandCO/Bearium/issues.
