Защита сертификатов

Rufox ограничивает использование Russian Trusted Root CA российскими доменными зонами и проверяет SCT — подписи журналов прозрачности сертификатов.

Если эта защита мешает открыть сайт, вы можете разрешить его. Проверка имени, срока действия, подписи и отзыва сертификата продолжит работать.

Разрешить обе дополнительные проверки для одного перехода в этой вкладке без сохранения исключения. Другой URL, редиректы и вложенные ресурсы требуют отдельного разрешения. Неиспользованное разрешение истекает через 60 секунд.

Разрешить выбранные сайты

Выберите домены выше или добавьте их вручную. Разрешение применяется только после нажатия кнопки.

Параметры исключения

Исключение действует для точного имени сайта и только для этого УЦ. Поддомены автоматически не разрешаются.

Режим проверки

Режим действует для всех сайтов с этим УЦ. Исключение SCT остаётся доступным в любом режиме.
