# Иконка Bearium

Основа — основной вариант из пользовательского наброска: красно-оранжевый
медведь в профиль, светлая морда, пламя и бордовый фон. Цветной рисунок выделен
из наброска с помощью imagegen; геометрия и градиенты сохранены в растровом
исходнике. Это подготовка по референсу, а не побитовое извлечение оригинала.

- `source/bearium-color.png` — цветной рисунок с прозрачностью.
- `source/bearium-monochrome.svg` — векторный монохромный вариант по тому же рисунку.
- `bearium-foreground.webp` — прозрачный Android foreground, 432×432.
- `bearium-foreground.xml` — bitmap drawable для adaptive icon.
- `bearium-monochrome.xml` — VectorDrawable для системной окраски.
- `bearium-background.xml` — отдельный бордовый градиент.
- `bearium-*.webp` — normal/round legacy icons для пяти density.
- `bearium-play-512.png` — непрозрачная квадратная иконка магазина без скругления.
- `preview.png` — проверка круглой, скруглённой и монохромной форм.

SVG цветного foreground и store содержат ссылку на PNG рядом с ними:
это композиции с растровым рисунком, не векторная перерисовка.
У монохромного SVG все контуры векторные. Android сам применяет форму маски
и цвета themed icon; цветной foreground помещён в центральную область 108dp.

Пересоздать экспорт: установить CairoSVG и ImageMagick и выполнить
`python scripts/export_branding.py` из репозитория. Для сборки браузера эти
зависимости не нужны — готовые ресурсы закоммичены.

При подготовке через imagegen использованы запросы: выделить основной цветной
рисунок без фона, надписей и изменения медведя; затем получить по этому рисунку
чистый одноцветный силуэт с прорезями ушей, глаза, носа и прядей пламени.

## Остальные иллюстрации и логотипы

[Комплект интерфейса](ui/README.md) заменяет лису в ошибках, настройках,
закладках, группах вкладок, альтернативных иконках и надписях Firefox.
Его экспорт: `python scripts/export_ui_branding.py` (требуется Pillow).
